🧭 Causal-Sim

An interactive Book of Why playground — tap a node to do() it and watch correlation turn into causation.

ℹ︎ Behind the scenes — how each simulation actually works
Every disease below is a causal diagram (a DAG): boxes are variables, arrows mean "this nudges that," and each arrow has a hidden strength. Here's what the buttons do:
  1. Virtual patients. We generate thousands of simulated people — start each variable as random noise, then push it through the arrows (value = Σ strength × parent + noise). That stream of patients is our observational data.
  2. Observed association. We fit a plain regression on that data — exactly what an epidemiologist does. It blends real cause with confounding, so it can mislead.
  3. do() — a virtual RCT. Tap a node to randomize it: we cut its incoming arrows so nothing upstream can bias it. The association is now pure cause.
  4. The model-entailed effect ◆. Given the arrow-strengths we assumed, we can read off the effect they imply (multiply strengths along each directed path, then add). This is what the model says must follow from its assumptions.
  5. Escaping confounding with data alone. The clever part: front-door (chain X→mediator→Y) and back-door (adjust for a measured common cause) recover that effect from observational data without an RCT — the heart of Pearl's Book of Why.
◆ = model-entailed, not measured: it follows necessarily from the assumed strengths — change the assumptions and it changes. It is not ground truth about any real disease, and real research has no such answer key (that's the whole difficulty). The strengths here are illustrative, not estimated from data.
